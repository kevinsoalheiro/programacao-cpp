# programacao-cpp

# 💻 Programação em C++

Repositório dedicado aos meus estudos de C++, contendo exercícios,
atividades acadêmicas e implementações desenvolvidas ao longo do aprendizado.

## 🎯 Objetivo

Registrar minha evolução na linguagem C++ e praticar conceitos fundamentais
de programação, estruturas de dados e programação orientada a objetos.

## 📚 Conteúdos estudados

- Variáveis e tipos de dados
- Entrada e saída de dados
- Operadores
- Estruturas condicionais
- Laços de repetição
- Funções
- Referências
- Ponteiros
- Structs
- Tipos Abstratos de Dados (TADs)
- Classes e objetos
- Encapsulamento
- Programação Orientada a Objetos
